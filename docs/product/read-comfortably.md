# Reading agent output for hours is comfortable, because how it reads is yours to set

> As a developer, I can set the typefaces, sizes, light or dark theme, colour schemes and the way each kind of file and each long conversation is shown to suit how I read, so that long sessions of reading agent output are comfortable.

## Without this, long reading sessions happen on the app's terms

The person spends hours reading what agents wrote: conversations, code,
documents and data. Type too small for their eyes, a theme wrong for the room, or
a file that always opens in a reading they never want is a small cost paid for
every one of those hours.

## You set typefaces, sizes, theme and how each kind of file reads, and see the result before you leave the setting

A person chooses the typefaces and sizes for the app's own words and, separately,
for data such as paths, code and identifiers. They are told when a typeface is
not on the machine, and when one chosen for data would not keep columns aligned.
They see each choice applied to a sample before leaving the setting. They switch
between light and dark.

For each kind of file, they choose which reading it opens in, which readings are
offered at all, the colour scheme each uses, and how editing code behaves. They
also choose how a conversation shows a batch of work that ran one piece after
another.

These are the person's own preferences on this machine and never travel with a
project. How they sized and folded things for reading is kept for them the next
time they open the app.

## Small costs paid for hours add up

Each preference on its own is minor. The person reads agent output for most of a
working day, so making it readable in their own way is what keeps that reading
from becoming the tiring part of the work.
