Refine loop

The draft and the critique share one conversation, named refine, so the critique reads what the draft wrote without being handed it. See the authoring reference for how a named session is declared.

Each pass does three things

  • The draft writes docs/ux/patterns/park-and-ask.md from the brief.
  • The critique lists what a builder would miss.
  • The loop stops when the critique is empty or after three passes.

A child input may only read a sibling earlier in the sequence.
