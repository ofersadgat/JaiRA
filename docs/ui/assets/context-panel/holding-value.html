Pick up where it left off

Work that stops, for any reason, carries on later from the step it stopped in. Nothing already done is run again or paid for again.

Use it when an interruption must not mean starting over

Use when. A run was paused, cancelled, lost to a crash or to closing the app, and the person wants the same run to go on.

Do not use when. The run went wrong at a step and the person wants that step again: use rewind.

Resuming names the step it picks up at

The button says which step the run picks up at and how much finished work it keeps.
