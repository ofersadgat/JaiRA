Safety policy

What an agent may run without asking. Rules are checked IN ORDER and the first match wins; anything no rule matches falls through to the built-in rules and then to the default below. A matcher is over parsed intent — a program, a subcommand, a flag — never a regex over the raw string, so a rule means the same thing however the command was spelled.
