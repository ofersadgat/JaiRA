Workflow self-test

Two prompt states run in sequence. The first is asked to say hello world; the second takes what it said as a declared input and reports whether it did. A pass means the model answered and that its output was validated, bound and carried into the next state.

What it runs

  1. debug/hello_world/sayasks for the greeting, publishes it as greeting: string
  2. debug/hello_world/checkreads .children.say.output.greeting, publishes passed: boolean and verdict: string
The state files, as they will be written
debug/hello_world/say.json
{
  "label": "Say hello",
  "outputs": {
    "greeting": {
      "schema": {
        "type": "string"
      }
    }
  },
  "operation": {
    "prompt": "Reply with exactly this and nothing else: Hello, world!"
  }
}

Installed
