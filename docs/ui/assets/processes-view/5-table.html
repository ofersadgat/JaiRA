5 · A table, like top

  • For the person who wants to see the machine: the Terminals tab, placed in the main view, becomes a table with one row per process, grouped by scope, sorted by any column (memory here). Columns: pid, program, who, CPU, memory, ports, start, output (where it can be read from), Stop.
  • This conversation's group comes first and keeps its marks (background, left running, escaped, this turn, ended with told Claude). The running dev server shows a live peek of its last lines under its row.
  • A press opens the row as a terminal in the side panel: its facts and its output, here a console window followed from when it was opened. Unreadable rows say why in the output column (parent's pipe, needs admin); JaiRA's own engine has no Stop.
  • Cost: dense and system-monitor-like; the transcript is a click away while it fills the main view.
