3 · The Terminals tab, Tree

  • The same tab, toggled to Tree: each scope, then each process and what it started, as JaiRA attributes them by parent and start time. The dev server is cmd → node → esbuild plus conhost, and its Stop stops all of them.
  • Every node has the row's anatomy and the row's hover. Here node.exe (the dev server's own node) shows the three places, … and Stop: a child can be watched or placed on its own.
  • The escaped node.exe hangs under WmiPrvSE.exe, the parent that really started it. It is open in line as its card: amber, its parent and the script it came from, and the file it writes followed from when it was opened.
  • Other scopes sit below, folded: Mine, JaiRA, System.
