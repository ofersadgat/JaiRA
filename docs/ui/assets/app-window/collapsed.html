Why does the rail skip a lane on a fork

The state rail skips a lane when a run forks at feature.ux. Why?

The lane for a fork is allocated when the child is entered, and a fork entered twice at the same ordinal reuses the first lane's slot. The second pass then draws one lane to the right.

The fix is to key lanes by instance, not by state id.
