12

Who decides what

Each layer row carries a strip of cells, one per line the stack knows (columns aligned across rows). A cell is solid where that layer's answer stands, hatched where it writes the line but a newer layer overrides it, and empty where it says nothing. So a layer whose strip is all hatched is doing nothing, and a new layer's preview row shows at once what it would actually decide.
