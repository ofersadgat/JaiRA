The permission board · the layer bar · 8 versions

The shield's board, its column groups the conversation's stack, oldest first: Root · ask-first, a standing layer project-safe (pinned to this project in settings), a named layer app/build, This run, This conversation, then the Result. Each version gives the layer heads three acts: add a set to the left of a layer, remove one, and swap one for another set.

What the acts change is this conversation's stack, not any set's file, so none of them asks "for every conversation". What each layer allows: the root and a named layer can be swapped, removed and added before; a standing layer is the project's (unpin it in settings, or from here); This run can only be forgotten; This conversation can be cleared. A layer added after this conversation's own lines is impossible — they are always newest — so "add to the left" of This conversation is how a set goes on top.
