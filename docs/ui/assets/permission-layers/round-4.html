The shield, round 4: one scope per kind, per layer

dark

The case designed for: inside a permission set, every permission of one kind shares one scope. If a set scopes read_file to some paths, its edit and write_file, where it sets them, use the same paths; its web_fetch uses one list of sites; its git_push and git_merge one list of branches. Different places get different layers. So a layer reads as: for each kind it touches — its scope, said once — then an answer per permission. It is the common case, not a rule: a set that breaks it is shown as an exception (design 10).

Under that case the shipped chat/auto is six scoped parts: everywhere (the defaults) · project ($PROJECT, $WORKTREE, $AGENT_WORKSPACE: reads smart) · credentials (8 patterns: read and write ask) · JaiRA files (.jaira: write and shell deny) · machine key (everything deny) · protected branches (main, master, release/**: push and merge ask). Over it: 2 chat/build-safe (paths packages/app) · 3 web/docs-sites (3 sites) — the current layer · 4 me/push-claude (branches claude/**) · 5 this run · 6 tools (programs node). The layer laid in before docs-sites is web/no-fetch (sites: any · web_fetch deny).

Exceptions, and splitting

When a set breaks the common case — two permissions of one kind with different places — the shield says so instead of hiding it. Today's one-file chat/auto is the example: its path permissions use 4 different scopes. A preset is a folder of layers

With one scope per kind per layer, a preset becomes a folder of small scoped layers, and the shield shows it as a folder in the stack: closed, one row with the kinds it touches; open, its parts in order, each with its scope and answers. One sentence per layer

With one scope per kind, every layer is one sentence per kind: "In these places, these permissions are this." The stack reads top to bottom as a short paragraph, newest first. Each underlined part is a control: the places open the scope picker, the permissions open the kind's list, the answer opens the mode menu. ＋ between sentences lays one in.
