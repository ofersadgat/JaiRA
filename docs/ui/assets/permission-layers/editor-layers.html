The permission board · layers as columns

Each layer is a set of answer columns, and a chip sits in the layer that sets it, in the column of its answer there. The same board opens two ways. From the shield it builds up: the root set the state names first, then each layer on top of it, oldest to newest, then the Result, frozen on the right. From the Tools view it starts from the Result alone; Show the source permission sets lays the layers out beside it, newest first. In both, a Result chip has an edge in the colour of the layer it came from, and a chip a newer layer overrules at the same place is struck through.

Layers
Moving within a layer changes that layer's answer. Drag a chip from one column to another in its own row, inside one layer's columns. The Result follows.
Moving between layers moves the place to the other layer, with the answer of the column you drop it in. Drop it on a collapsed layer to keep its answer. Built in can't be changed: a chip dragged out of it is copied.
Moving in the Result answers for this session, like "allow for this session" in a request. Dragging a Result chip onto a layer keeps that answer there.
