Refine loop
The draft and the critique share one conversation, named refine, so the critique reads what the draft wrote. See the authoring reference for how a named session is declared.

Each pass does three things
• The draft writes docs/ux/patterns/park-and-ask.md from the brief, following every pattern the brief names and the writing standard in the prompt.
• The critique lists what a builder would miss.
• Stop when the critique is empty or after three passes.

• ☑ name the session
• ☐ add target: ask as the escape

A child input may only read a sibling earlier in the sequence.
