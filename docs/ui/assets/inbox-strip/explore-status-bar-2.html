Status bar · round 2 · rings that belong to a project

This round builds on 02 Rings: every top-level chat or task is a segmented ring, the same as in the chat list. Each design tries a different way to tie rings to their project without the bulk of lanes. All of them shrink in the same steps as the bar narrows, which brings in the dock and the slim bar:
  1. full titles;
  2. shorter titles;
  3. rings only (the dock), from the last project back, with the title in a hover card;
  4. those projects fold to one tile each (the slim bar), with their asks counted on it, while the first project keeps its titles;
  5. only then +N more.
There are three cases: today (4 asks, 3 chats, 1 project), busy (8 asks, 6 entries, 3 projects) and crowded (14 asks, 12 entries, 5 projects). Drag the width slider to watch each design shrink.
