Permission sets

Which tools are offered, and what happens when each is called. A state names one as $/permission-sets/<bucket>/<name>; a bucket is a place with its own versions of the same names.

chatbuilt in
chat_controlbuilt in
chat / auto built inno state names it
readread a file in the workspace
globlist files matching a pattern
grepsearch file contents for a pattern
editreplace exact text in an existing file
writecreate a file, or replace one whole
showproduce something to look at — a page, a drawing, a document
bashthe shell — and the mode for any command not named below
MCPnothing here
Otheranything not listed above — an agent's own tools with no equal here included
