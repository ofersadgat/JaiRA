1Memoize

Remember what a model answered, and reuse it when the identical call is made again. It saves real money and is not a pure optimization: a re-run returns the first run's answer rather than asking again.

Outermost, so a hit costs nothing else — no slot acquired, no retry loop entered.

2Retry

Re-attempt a call that failed for a reason worth trying again — a 429, a dropped connection, or output that did not satisfy its schema.

Outside the rate limiter, so each attempt goes through admission separately rather than holding one slot across the whole loop and its backoff.

transient attemptsnumberExtra attempts for a retriable failure. Empty means none — the first failure is the answer.prompt.routes.claude-cli.steps.retry.transient

max backoff (ms)numberA ceiling on that growth, so a long outage does not turn into a very long sleep.prompt.routes.claude-cli.steps.retry.maxBackoffMs

3Rate limit

Hold each call until there is a concurrency slot and enough rate headroom, and back off automatically when the provider says no.

Immediately around the call, inside retry.

4Deadline

Give a call a wall-clock window, and refuse to start one that cannot finish inside it.

Innermost, so the window bounds the call itself rather than the queueing and the backoff — neither of which is the call's own latency.
