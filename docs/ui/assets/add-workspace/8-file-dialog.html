  • Looks and behaves like the save dialog people already know: back, forward, up, a breadcrumb from the root, a filter field, sortable columns.
  • Kind and Changed columns help pick between folders; "Show hidden folders" for dotfolders. Needs files:browse to return each folder's modified time.
