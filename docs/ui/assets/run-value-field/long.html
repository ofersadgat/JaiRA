--- id: ui/components/pause-control type: ui-component status: proposed updated: 2026-09-13 realizes: [ux/patterns/button-says-what-will-happen] serves: [product/pick-up-where-it-left-off] --- # Pause control One button on the task card's hover row that reads `Pause` while the task runs and `Resume` once it has stopped. ## A pause control is the one verb that stops work without releasing it **Use when.** A running task can be held and picked up later with its worktree and seat kept. **Do not use when.** The work should end and give its resources back: use the stop verb in the card's menu. ## The word says what a click will do | State | Rendered as | | --- | --- | | running | `Pause` in a ghost button | | pausing | `Pausing…` with the button dimmed | | paused | `Resume` in the primary fill |
