new Everything Claude Design's canvas does, drawn in JaiRA's chrome. Tools (left): pointer moves and resizes elements and artboards, hand pans, text retypes copy in place, artboard draws a new frame (or wraps the selection in a stack or grid), note drops a sticky, pen draws freehand, rectangle, oval, arrow and line draw shapes. Edits to an element write its .dc.html; notes and shapes are notes entries in canvas.json, the person's (red oval, arrow and sticky above). Name strips carry each artboard's title; an is_interactive one gets the blue mark and ▶. Play runs the artboards, links between them included; Export gives PNG or PDF per artboard. A save is a new version marked yours; the model's next publish over it is refused and it re-reads, as on claude.ai.
