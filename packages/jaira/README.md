# jaira

Interactive agent orchestration: hierarchical workflows with humans in the loop.

```bash
npx jaira --help
```

This package is a thin wrapper that owns the unscoped name. The CLI lives in
[`@jaira/cli`](https://www.npmjs.com/package/@jaira/cli), pinned here to an exact
version; the two ship together and share a version number.

Source, docs, and issues: https://github.com/ofersadgat/JaiRA
